# NUTS — no utility tokens

A stupid-simple, single-page token launchpad with absolutely no features. No wallet, no minting, no forms, no nav, no footer, no auth, no database. Just the nuts.

## Run it locally

```bash
npm install
npm run dev -- --port 47291
```

Then open http://localhost:47291

## Build

```bash
npm run build
npm start -- --port 47291
```

That's it. There is nothing else to do here.
